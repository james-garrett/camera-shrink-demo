# Camera Shrink Demo

This project aims to experiment with dynamically scaling the user viewport & UI for an FPS game while not compromising performance. The eventual goal is to have a prototype which combines the aesthetics of early 90s fps games (ala System Shock and Ultima Underworld) - which leveraged a lot of adventure game UI elements - and use the overwhelming nature of that UX experience to convey a sense of disconnect between the player and the world. The game will eventually have a toggle button that switches the mouse cursor from a view controller to a menu cursor, such that all interactions and UI within the game feel entirely diagetic. 

This demo is early in development and uses Godot 4.4. For the moment, getting a MVP is priority. Then, improving performance by modifying the UI-rescale code. I'm hoping to develop other prototypes modularly and see if the ideas connect when put together.
